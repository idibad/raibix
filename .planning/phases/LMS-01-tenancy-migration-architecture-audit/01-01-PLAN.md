<objective>
Audit database migration separation and add CentralConnection traits to all central-only Eloquent models.

Purpose: Prevent SQL "table not found" errors when central entities (plans, coupons, SaaS settings, activity logs) are referenced inside tenant request lifecycles.
Output: Hardened central models with CentralConnection trait and verified migration separation.
</objective>

    app/Models/SaaSActivityLog.php,
    app/Models/TenantSubscription.php
  </files>
  <read_first>
    app/Models/Referral.php,
    app/Models/SaaSTransaction.php
  </read_first>
  <action>
    Add `use Stancl\Tenancy\Database\Concerns\CentralConnection;` and `use CentralConnection;` inside:

    - `app/Models/SaaSActivityLog.php`

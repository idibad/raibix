<objective>
Refactor heavy synchronous bulk operations (monthly fee challan generation and CSV student imports) into asynchronous tenant-aware queued background jobs.

Purpose: Prevent HTTP request timeouts, unblock web server workers during long batch operations, and ensure retryability on queue failure.
Output: Queued job classes, refactored controllers, and automated feature tests.
</objective>

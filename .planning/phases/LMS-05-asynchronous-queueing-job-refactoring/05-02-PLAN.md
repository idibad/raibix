<objective>
Refactor synchronous third-party SMS and WhatsApp gateway notifications into tenant-aware queued jobs.

Purpose: Isolate external network latency (Twilio, UrduBit, PariSMS, WhatsApp Business API) from HTTP user requests and ensure notification failures can be retried automatically.
Output: Notification jobs, updated service layer, and automated feature tests.
</objective>

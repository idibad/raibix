Harden application configuration files for session security, cookie scoping, cache drivers, and error handling.

Output: Hardened `config/session.php` and `config/cache.php`.
</objective>

  <action>
    Update `config/session.php`:
    - Ensure `'secure' => env('SESSION_SECURE_COOKIE', env('APP_ENV') === 'production')`
